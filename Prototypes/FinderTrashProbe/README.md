# FinderTrashProbe — как Finder удаляет по ⌘⌫ и возвращает по ⌘Z

Одноразовый исследовательский инструмент для v0.6. Ementium в режиме «следовать» будет удалять картинку,
отправляя Finder `⌘⌫` (как сейчас отправляет стрелки), и возвращать её по `⌘Z`. Прототип выясняет:

- куда Finder ставит выделение после удаления в каждом виде (список, колонки, значки, галерея);
- исчезает ли файл и за сколько;
- возвращает ли `⌘Z` файл и выделяет ли его;
- что при двух удалениях подряд.

Тестовая папка — `testdata/trash` (в git не попадает): картинки вперемешку с документами,
`01.png 02.png 03.txt 04.png 05.txt 06.txt 07.png 08.txt 09.png`. Файлы пересоздаются перед каждым случаем.
Работает только с ними; не вернувшиеся по `⌘Z` пустышки остаются в Корзине.

## Запуск

Из Terminal.app (нужны «Универсальный доступ» и «Автоматизация → Finder», как для FinderFollowProbe):

```bash
cd ~/Documents/Obsidian/Claude/Ementium/Prototypes/FinderTrashProbe
./run.sh     # ~2 минуты, мышь и клавиатуру не трогать; Finder будет издавать звук Корзины
```

Лог — в `logs/` (в git не попадает).

## Результаты (12.10.2026, macOS 27)

Папка `01.png 02.png 03.txt 04.png 05.txt 06.txt 07.png 08.txt 09.png`, `⌘⌫` и `⌘Z` — напрямую процессу Finder.

| | Список | Колонки | Значки | Галерея |
|---|---|---|---|---|
| `⌘⌫` в середине | следующий файл (картинка или документ) | так же | так же* | так же |
| `⌘⌫` последнего файла | выделение пустое | пустое (до 1,45 с) | пустое | пустое |
| Файл исчезает | 0,2–0,55 с | 0,2–1,45 с | 0,2 с | 0,2–0,45 с |
| `⌘Z` | файл возвращается за 0,25–0,8 с; выделяется **не всегда** (2 из 5) | выделяется | выделяется | выделяется |
| Выделение через AX (`AXSelectedRows` / `AXSelectedChildren`) | работает | работает | работает | работает |

\* В первом (прерванном) прогоне в «значках» выделение после удаления было пустым всегда, во втором — следующий файл.
Два удаления подряд и два `⌘Z` подряд отрабатывают по порядку.

**Вывод для v0.6.** На выделение, которое ставит Finder, полагаться нельзя. Ementium до `⌘⌫` сам находит цель
(ближайшую картинку впереди, иначе позади), после исчезновения файла выделяет её через AX и показывает; после `⌘Z`
дожидается возвращения файла и тоже выделяет его сам. `⌘Z` — только за удалённое в этом сеансе.

Первый прогон завис в галерее: `NSAppleScript` без таймаута ждёт ответа Finder до 2 минут — теперь `with timeout of 10 seconds`.
