# RawProbe — замеры декодирования RAW

Одноразовый инструмент: для каждого файла — размер, встроенное превью, время показа под экран и полного декодирования (как это делает `ImageLoader`). Разрешения не нужны.

```bash
swift Prototypes/RawProbe/raw.swift ~/Downloads/raw/*
```

## Результаты (11.10.2026, MacBook Air, macOS 27, экран 3420 px по длинной стороне)

| Формат | Под экран из RAW | Встроенное превью | Полное разрешение |
|---|---|---|---|
| ARW (Sony, 14–24 Мп) | 360–510 мс | 1616×1080, 8–18 мс | 260–450 мс, до 192 МБ |
| RW2 (Panasonic, 24 Мп) | 446 мс | 1920×1280, 8 мс | 1,3 с, 192 МБ |
| DNG (Canon, 50 Мп) | 620 мс | 683×1024, 7 мс | 0,9 с, ~400 МБ |
| NEF (Nikon, 12–24 Мп) | 60–100 мс | полноразмерное, 31–74 мс | 28–50 мс* |

\* Для NEF ImageIO, судя по объёму в памяти (8 бит на канал вместо 16), берёт встроенный полноразмерный JPEG.

Поворот по EXIF учитывается (DNG с ориентацией 6 — вертикальный). Все 11 образцов читаются; у каждого формата свой `UTType` (`com.sony.arw-raw-image`, `com.adobe.raw-image`…), и все они соответствуют `public.camera-raw-image`.

**Вывод для v0.3:** для RAW сначала показывать встроенное превью (мгновенно), а RAW под экран декодировать в фоне и подменять. Если превью уже не меньше нужного (NEF) — второе декодирование не нужно.
