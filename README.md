# Ementium

**Ementium** — минималистичный просмотрщик изображений для macOS, который заменяет стандартный Quick Look для картинок. Выделите изображение в Finder, нажмите **Пробел**, и оно откроется на весь экран поверх затемнённого фона. Стрелками листаются остальные изображения в той же папке, **Esc** закрывает просмотр.

Интерфейса почти нет: нет панелей, кнопок и Dock-иконки. Есть только окно настроек.

## Идея

Встроенный Quick Look удобен, но для просмотра фотографий у него есть недостатки: окно не занимает весь экран, вокруг остаются элементы интерфейса, а листать папку можно только при выделении нескольких файлов. Ementium сохраняет привычный жест (Пробел в Finder) и делает следующее:

- открывает изображение сразу на весь экран;
- затемняет всё вокруг, чтобы ничего не отвлекало;
- позволяет листать все изображения каталога, а не только выделенные;
- закрывается одной клавишей.

## Возможности

- Перехват клавиши **Пробел** в Finder, когда выделено изображение.
- Файлы, которые не являются изображениями (PDF, видео, документы и др.), не открываются, а просто передаются стандартному Quick Look без изменений.
- Полноэкранный показ поверх всех окон с регулируемым уровнем затемнения фона.
- Навигация по изображениям текущего каталога стрелками (все другие файлы не являющиеся изображениями, приложение "не видит").
- Предзагрузка соседних изображений, чтобы листание было мгновенным.
- Показ на том мониторе, где находится активное окно Finder.
- Работа в фоне без иконки в Dock (агентское приложение).
- Автозапуск при входе в систему.
- Окно настроек — единственный элемент интерфейса.

## Управление

| Клавиша                | Действие                                                      |
| ---------------------- | ------------------------------------------------------------- |
| `Пробел` (в Finder)    | Открыть выделенное изображение                                |
| `→` / `↓`              | Следующее изображение в каталоге                              |
| `←` / `↑`              | Предыдущее изображение в каталоге                             |
| `Esc`                  | Закрыть просмотр                                              |
| `Пробел` (в просмотре) | Закрыть просмотр (как в Quick Look, отключается в настройках) |
| `Home` / `End`         | Первое / последнее изображение (план)                         |
| `⌘,`                   | Открыть настройки                                             |
| `+`                    | Увеличить масштаб                                             |
| `-`                    | Уменьшить масштаб                                             |

> **Примечание.** `Esc` закрывает окно просмотра, но не завершает само приложение: процесс Ementium должен работать постоянно, иначе перехват Пробела в Finder перестанет работать. Полностью выйти можно через окно настроек или пункт в строке меню (если он включён).

## Поддерживаемые форматы

Декодирование выполняет системный фреймворк **ImageIO**, поэтому набор форматов зависит от версии macOS.

| Формат | Расширения | Примечание |
|---|---|---|
| JPEG | `.jpg`, `.jpeg` | |
| PNG | `.png` | |
| HEIF / HEIC | `.heic`, `.heif` | |
| TIFF | `.tif`, `.tiff` | |
| GIF | `.gif` | Анимация — в плане |
| BMP | `.bmp` | |
| WebP | `.webp` | Только чтение |
| AVIF | `.avif` | Требует более новой macOS |
| JPEG XL | `.jxl` | Требует более новой macOS |
| PSD | `.psd` | Отображается сведённое изображение |
| RAW | `.cr2`, `.cr3`, `.nef`, `.arw`, `.dng` и др. | Через встроенную поддержку RAW в macOS |

Перед выпуском список нужно проверить на минимальной поддерживаемой версии macOS. Определять тип файла следует через `UTType` (соответствие `public.image`), а не по расширению.

## Как это работает

Приложение состоит из нескольких независимых компонентов.

```
┌──────────────┐   Пробел   ┌───────────────┐  выделение  ┌──────────────┐
│   Finder     │──────────▶│ KeyInterceptor│────────────▶│FinderBridge  │
└──────────────┘            └───────┬───────┘             └──────┬───────┘
                                    │ это изображение?           │ URL файла
                                    ▼                            ▼
                            ┌───────────────┐            ┌──────────────┐
                            │ ViewerWindow  │◀───────────│ImageDirectory│
                            │ (оверлей)     │  список    │ + ImageCache │
                            └───────────────┘            └──────────────┘
```

### 1. `KeyInterceptor` — перехват клавиатуры

- Использует **`CGEventTap`** на уровне сессии и слушает события `keyDown`.
- Реагирует только если выполнены все условия:
  - активное приложение — Finder (`com.apple.finder`);
  - нажат Пробел без модификаторов;
  - фокус не в текстовом поле (переименование файла, поиск, адресная строка). Проверяется через Accessibility API: роль сфокусированного элемента не `AXTextField` / `AXTextArea`.
- Если условия выполнены, событие поглощается (callback возвращает `nil`), поэтому Quick Look не открывается.
- Callback должен работать очень быстро: если он задерживается, система отключает tap (`kCGEventTapDisabledByTimeout`). Поэтому медленные операции (получение выделения из Finder) выполняются асинхронно, а tap после отключения повторно включается.

### 2. `FinderBridge` — получение выделенных файлов

- Запрашивает выделение Finder через Apple Events (AppleScript или ScriptingBridge): `tell application "Finder" to get selection as alias list`.
- Возвращает URL выделенного файла и его каталог.
- Альтернатива для исследования — чтение выделения через Accessibility API (быстрее, но менее надёжно в разных режимах отображения Finder).

### 3. `ImageDirectory` — список изображений каталога

- Перечисляет файлы каталога и оставляет только изображения (`UTType.conforms(to: .image)`).
- Сортирует по имени как Finder: `localizedStandardCompare` (естественная сортировка, «file2» перед «file10»).
- Определяет индекс текущего файла и обрабатывает переходы к соседним.

### 4. `ImageCache` — загрузка и предзагрузка

- Декодирует изображения через `CGImageSourceCreateThumbnailAtIndex` с ограничением по размеру экрана, а не загружает оригинал целиком. Это важно для больших фото и RAW.
- Учитывает EXIF-ориентацию (`kCGImageSourceCreateThumbnailWithTransform`).
- Держит в памяти текущее изображение и несколько соседних (окно ±N), остальные выгружает.
- Загрузка выполняется в фоне, интерфейс не блокируется.

### 5. `ViewerWindow` — окно просмотра

- Безрамочное `NSPanel` / `NSWindow` на весь экран (`styleMask: .borderless`), уровень выше обычных окон.
- Фон — чёрный с настраиваемой прозрачностью, изображение по центру в режиме «вписать в экран».
- Плавное появление и исчезновение (fade).
- Окно получает фокус клавиатуры, пока открыто; при закрытии фокус возвращается Finder.
- Реализация на **AppKit**, так как нужен точный контроль над уровнем окна, фокусом и обработкой клавиш.

### 6. `Settings` — окно настроек

- Реализация на **SwiftUI** (`Settings` scene).
- Хранение настроек в `UserDefaults` / `@AppStorage`.

### Жизненный цикл приложения

- `LSUIElement = YES` в `Info.plist`: нет иконки в Dock и главного меню.
- Автозапуск через `SMAppService.mainApp` (ServiceManagement).
- При первом запуске открывается окно настроек с инструкцией по выдаче разрешений.

## Системные разрешения

Без этих разрешений перехват работать не будет. Приложение должно проверять их при запуске и показывать понятную инструкцию.

| Разрешение | Зачем | Как проверить |
|---|---|---|
| **Универсальный доступ** (Accessibility) | Создание `CGEventTap`, поглощение событий, проверка фокуса в Finder | `AXIsProcessTrustedWithOptions` |
| **Мониторинг ввода** (Input Monitoring) | Может потребоваться для прослушивания клавиатуры в зависимости от версии macOS | `CGPreflightListenEventAccess` / `CGRequestListenEventAccess` |
| **Автоматизация → Finder** (Apple Events) | Получение выделенных файлов | Ключ `NSAppleEventsUsageDescription` в `Info.plist`, запрос при первом обращении |

Разрешения привязаны к подписи приложения. При разработке с меняющейся подписью macOS может «забыть» выданный доступ, тогда его нужно удалить и выдать заново в **Системные настройки → Конфиденциальность и безопасность**.

## Требования

- macOS 14 Sonoma или новее (предварительно; окончательно уточнить по поддержке форматов и API).
- Xcode 16 или новее.
- Swift 5.10+ / Swift 6.
- Apple Silicon и Intel (Universal binary).

## Сборка и запуск

```bash
git clone <url-репозитория>
cd Ementium
open Ementium.xcodeproj
```

1. В Xcode выберите свою команду разработчика: **Signing & Capabilities → Team**.
2. Отключите **App Sandbox** (см. [Ограничения](#ограничения)).
3. Включите **Hardened Runtime** и в нём **Apple Events**.
4. Соберите и запустите схему `Ementium` (`⌘R`).
5. При первом запуске выдайте запрошенные разрешения и перезапустите приложение.

Для распространения вне Mac App Store приложение нужно подписать сертификатом **Developer ID** и пройти **нотаризацию** (`notarytool`).

## Ограничения

- **Нет App Sandbox, нет Mac App Store.** Глобальный перехват клавиатуры через `CGEventTap` и управление Finder через Apple Events несовместимы с песочницей, а приложения без песочницы нельзя публиковать в Mac App Store. Распространение — через Developer ID и нотаризацию.
- Работа зависит от поведения Finder. Обновления macOS могут изменить структуру Accessibility-элементов Finder или работу Apple Events.
- Перехват работает только в Finder. В других приложениях (диалоги открытия файлов, сторонние файловые менеджеры) по-прежнему открывается стандартный Quick Look.

## Открытые вопросы

- **Передача не-изображений в Quick Look.** Решение о поглощении Пробела принимается синхронно, а выделение Finder получается асинхронно. Варианты:
  1. Поглощать Пробел всегда, а для не-изображений открывать собственную панель `QLPreviewPanel`.
  2. Получать выделение быстро через Accessibility API прямо в callback и пропускать событие, если это не изображение.
  3. Поглощать событие и при необходимости синтезировать Пробел обратно в Finder, временно отключив перехват.
- **Несколько выделенных файлов.** Листать только выделенные (как Quick Look) или весь каталог, начиная с первого выделенного?
- **Порядок сортировки.** Повторять текущую сортировку окна Finder (дата, размер) или всегда сортировать по имени?
- **Минимальная версия macOS** — зависит от нужных форматов (AVIF, JPEG XL).
